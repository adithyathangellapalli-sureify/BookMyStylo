# ADR-005 — Rename Snipbook → BookMyStylo; brand Direction A ("the mirror")

**Status:** accepted · decided on the naming board (Aug 2026), applied on rebuild (Oct 2026)

## Context
"Snipbook" spent the whole name on scissors while the product had become stylist-first. The naming board evaluated seven candidates. The founder's suggestion "Book my Styler" had three problems (BookMy is contested trademark territory in India, "styler" is an appliance, 14 characters truncates on home screens); the repair that kept the stylist-first strategy was **Stylo**, shipped as **BookMyStylo** with every mark drawn so the prefix can be dropped later.

## Decision
- Name: **BookMyStylo**; package scope `@bookmystylo/*`; partner app is "BookMyStylo for Salons", the console is "BookMyStylo Console".
- Mark: Direction A — the O in STYLO is a mirror on a stand (ring + highlight arc + stem). The wordmark is a mono "BOOK MY" kicker over Bodoni "STYL◯"; `compact` mode drops the kicker in app bars; the icon tile is the mirror reversed out of the accent.
- Palette: brass `#a9781f` on a cool slate ground (light) / `#d4a43a` on near-black (dark). Semantic slot colours unchanged. The old striped barber pole is retired.

## Still open (from the board)
Trademark search (class 44 + 42/9), `.in` domain, Play/App Store name, Instagram/WhatsApp handles — none verified. If the BookMy prefix is blocked, ship as plain **Stylo**: the mark and layout already work without it.
